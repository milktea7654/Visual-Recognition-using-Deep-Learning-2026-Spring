# NYCU Computer Vision 2026 Homework

This repository contains the homework submissions for NYCU Computer Vision
2026 Spring.

## Repository Layout

```text
.
├── HW1/
│   ├── README.md
│   ├── requirements.txt
│   ├── config.py
│   ├── train.py
│   ├── inference.py
│   └── utils.py
├── HW2/
│   ├── README.md
│   ├── requirements.txt
│   ├── config.py
│   ├── dataset.py
│   ├── model.py
│   ├── train.py
│   └── inference.py
├── HW3/
│   ├── README.md
│   ├── requirements.txt
│   ├── config.py
│   ├── dataset.py
│   ├── model.py
│   ├── train.py
│   └── inference.py
└── HW4/
    ├── README.md
    ├── requirements.txt
    ├── configs/
    ├── model/
    ├── dataset.py
    ├── train.py
    └── inference.py
```

Each homework folder is self-contained. Enter the target homework directory
before installing dependencies, training, or running inference.

## Ignored Local Files

Datasets, model checkpoints, generated predictions, training outputs, cache
files, and the separate final-project repositories are intentionally ignored by
Git.
